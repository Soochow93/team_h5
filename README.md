# 甜美雪服预订单 H5 Demo

这是一个面向雪服租赁门店的移动端预订单管理 Demo。项目使用原生 HTML、CSS 和 JavaScript 实现，无需构建工具和后端服务，适合直接在浏览器中运行和演示。

页面底部提供三个入口，分别是“预订单”“订单管理”和“设置”。

## 功能概览

### 新建预订单

- 订单类型固定为“预订单”
- 门店默认显示“甜美雪服”
- 销售人员支持选择和自定义输入
- 订单状态支持“已付款”和“未付款”
- 预订日期支持日历选择
- 归还时间支持在同一个弹窗中选择日期和时间
- 客户姓名和手机号分开录入
- 意向款式支持多选
- 每个意向款式可以继续选择尺码
- 套餐内容支持多选
- 支持填写套数、价格和备注
- 支持清空表单
- 支持生成预订单预览
- 支持复制生成的预订单文本

### 订单管理

- 自动记录已经生成的预订单
- 展示客户、销售人员、手机号、订单状态、预订日期和归还日期
- 展示套数、价格、意向款式和套餐
- 展示订单创建时间
- 支持按销售人员筛选
- 支持按订单状态筛选
- 支持按手机号查询
- 支持按预订日期筛选
- 支持复制历史预订单
- 显示当前订单数量

### 设置

设置页面支持维护新建预订单使用的基础配置。

- 销售人员的新增和删除
- 意向款式的新增和删除
- 为意向款式新增和删除尺码
- 套餐内容的新增和删除
- 门店开始营业时间和结束营业时间配置
- 配置保存后同步到新建预订单、预订单预览和订单管理

## 技术实现

- HTML5
- CSS3
- 原生 JavaScript
- 浏览器 `localStorage` 持久化配置和订单
- 使用原生日期和时间选择交互
- 移动端优先的响应式布局
- 不依赖前端框架和第三方运行时

## 本地运行

项目不需要安装依赖，使用 Python 静态文件服务器即可运行。

```bash
cd /Users/soochow/python-workspace/team_h5
python3 -m http.server 4173
```

启动后访问：

```text
http://127.0.0.1:4173/index.html
```

也可以在其他目录中通过绝对路径启动：

```bash
python3 -m http.server 4173 --directory /Users/soochow/python-workspace/team_h5
```

如果 4173 端口已经被占用，可以先确认正在运行的服务，避免重复启动多个开发服务。

```bash
lsof -nP -iTCP:4173 -sTCP:LISTEN
```

## 使用流程

1. 打开“预订单”页面。
2. 选择销售人员和订单状态。
3. 选择预订日期和归还时间。
4. 填写客户姓名、手机号、套数和价格。
5. 选择意向款式并为款式选择尺码。
6. 选择套餐内容并填写备注。
7. 点击“生成预订单”。
8. 在预览弹窗中确认订单内容。
9. 点击“复制订单”复制文本，或点击“完成”保存订单。
10. 进入“订单管理”查看和筛选已保存的预订单。

## 数据存储

项目使用浏览器本地存储保存数据，不需要数据库。

- `sweet-snow-orders` 保存已生成的预订单
- `sweet-snow-order-config` 保存销售人员、意向款式、尺码、套餐和门店营业时间配置

数据仅保存在当前浏览器和当前域名下。更换浏览器、清除站点数据或使用其他域名访问后，数据不会自动同步。

## 默认配置

首次打开项目时会加载以下默认配置。日期字段会根据当前日期初始化，门店营业时间和其他选项使用以下配置：

- 销售人员：乐乐、发财、娟娟、黑黑
- 意向款式：星芒粉色、天使羽翼、小黄鸡、星河蓝
- 默认尺码：S码、M码、L码
- 套餐内容：雪服、雪裤、手套、头盔、雪镜、护臀、护膝、小乌龟护臀护膝
- 门店营业时间：09:00-20:00

配置修改后需要点击设置页面底部的“保存设置”完成保存。
